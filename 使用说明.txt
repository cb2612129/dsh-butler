DSH 管家 v3.0  ——  DeepSeek Harness Web 服务的启停小工具
==========================================================

【怎么用】
  双击桌面上的「DSH 管家」图标（或者双击文件夹里的 DSH管家.exe）。
  打开是一个小控制面板；点右上角的 × 不会退出，它会缩到右下角托盘继续待命。

  第一次运行：管家会自动去找 DSH 装在哪儿 —— 先看自己周围，再看桌面/文档/下载，
  最后扫各盘根目录下面一层。找到了就直接能用；万一没找到，会弹个提示，
  然后打开设置面板让你手动选一次（就是含 package.json、平时敲 pnpm dsh web 的那个文件夹）。
  选过一次就记住了，以后不用再管。

【主界面】
  状态卡片（顶部）
     ● 运行中  v3.0         状态 + 版本号
     端口 3080 · PID 20540   服务信息
     ⏱ 已运行 1 小时 10 分   独立徽章，一眼看到服务跑了多久
     ⚙ 设置                 齿轮按钮 → 打开设置面板
     ☀/☾                    白天 / 夜间主题开关（切换有渐变过渡）

  四个主按钮：启动服务 / 停止服务 / 重启服务 / 打开页面

  浏览器图标条（v2.6 新增，主界面中间那一排）
     · 点哪个图标，以后「打开页面」就用哪个浏览器，立即生效并记住
     · 选中的那个：绿框加粗 + 淡绿底 + 名字加粗，一眼看得出用的是谁
     · 装得多显示不下时：滚轮上下滚，或者按住下面的绿色小滑块左右拖
     · 每个胶囊宽度按自己的名字来，短的（豆包 / 千问）不会留一大截空白
       （哪一项被选中，条会自动滚到看得见的位置）
     · 第一项「系统默认」= 交给 Windows 决定，跟着系统默认浏览器走

  底部按钮（v2.6）
     左下角两个小鲸鱼按钮：
       对话   打开 DeepSeek 网页版（免费对话）  chat.deepseek.com
       用量   打开 DeepSeek 平台 · API 用量页  platform.deepseek.com/usage
       两个都跟你选的浏览器走（没指定就用系统默认），鼠标停上去有中文提示
     右下角：
       退出   真的退出管家（点 × 只是缩到托盘）；
              如果设置里勾了「退出时同时停止 DSH 服务」，退出时会连服务一起停掉
     日志相关的三个操作（打开服务日志 / 打开管家日志 / 清空服务日志）
     都在设置面板的「其它」里，主界面上不再重复放一份

【系统托盘】
  · 点 × 后程序缩到右下角托盘，服务继续跑
  · 托盘图标右下角有状态点：绿 = 运行中，红 = 已停止
  · 鼠标悬停能看到状态和运行时长
  · 双击托盘图标 = 直接打开服务页面
  · 右键托盘图标 = 快捷菜单：
      打开控制台 / 打开服务页面 / 启动服务 / 停止服务 / 重启服务 /
      切换白天夜间 / 设置… / 退出（停止服务并关闭）

【设置面板】（v2.6）
  启动与常驻
    开机时自动启动管家          ← 写入注册表启动项，可随时关闭
    开机时顺便把 DSH 服务也启动起来
    关闭窗口时：最小化到系统托盘 / 直接退出
    退出时同时停止 DSH 服务      ← v2.6 新增，管的是「退出」按钮和托盘退出
  界面
    主题：白天 / 夜间 / 跟随时间（7:00-19:00 自动用白天配色）
  服务
    端口（默认 3080，可在界面里改）
    启动命令（留空 = 自动识别，见下）
    DSH 工作目录（可点“浏览”选择；留空 = 用全局安装的 DSH）
    启动成功后自动打开浏览器
    服务异常退出时自动重启（守护模式，每 30 秒检查）

    启动命令留空时，管家按环境自动挑：
      · 源码目录 + 有 pnpm   →  pnpm dsh web --no-open
      · 源码目录 + 只有 npm  →  npm run dsh -- web --no-open
      · 全局安装的 DSH       →  dsh web --no-open（这时工作目录留空）
    想用别的命令（带参数、或者自定义脚本），直接在这一栏写完整命令即可。
  其它
    在开始菜单中显示（之后可右键固定到任务栏）
    打开管家日志 / 打开服务日志 / 清空服务日志（v2.6 新增）/ 恢复默认设置
  说明：浏览器选择已经搬到主界面（原来在设置里的那一项去掉了）

【关于「固定到任务栏」】
  Windows 11 禁止程序自动固定任务栏（防流氓软件策略），所以需要两步：
    1. 在设置面板里勾选「在开始菜单中显示」
    2. 打开开始菜单，找到 DSH 管家 → 右键 → 固定到任务栏
  （只需做一次，之后就能从任务栏直接打开）

【文件说明】（运行只要前四个 + assets 那一张图）
  DSH管家.exe       启动器（无窗口启动，双击这个）
  DSH管家.ps1       主程序，配置区（端口/目录/日志路径）在最上面
  DSH管家.ico       程序图标（7 个尺寸：256/128/64/48/32/24/16）
  使用说明.txt      就是本文件
  assets\           只有一张图：deepseek-whale.png
                    （主界面左下角「对话 / 用量」两个按钮上的小鲸鱼）

  设计过程稿（配色方案、各版本设计稿 HTML、图标草图、鲸鱼原图）都挪到了
  隔壁的「DSH管家-设计稿」文件夹，跟程序分开放，不影响运行，可以整个删掉。

【日志与排错】
  管家自己的日志： %TEMP%\dsh-butler.log     （双击没反应时先看这个）
  DSH 服务日志：   %TEMP%\dsh-web.log
  日志里记录了每次启动、主题、端口、浏览器探测、设置保存等信息。

【版本历史】一路是怎么长出来的

  v2.1  双主题诞生：白天米黄 / 夜间石墨，加 ☀/☾ 开关和 1.1 秒渐变过渡
  v2.2  收拾屋子：代码整理、目录整理、全局出错兜底日志（双击没反应时能查）
  v2.3  能看时长了：状态卡加「已运行 x 小时」，第一次有了设置面板（选浏览器 / 工作目录）
  v2.4  颜值期：图标体系升级（真齿轮）、时长改成独立徽章、状态卡片重新排版
  v2.5  能常驻了：系统托盘 + 开机自启 + 开始菜单入口 + 设置面板重做 + 守护模式
  v2.6  细节打磨：主界面加浏览器图标条（点图标换浏览器，宽度自适应）
        底部改成「对话 / 用量 / 退出」，两个小鲸鱼按钮直达 DeepSeek 网页版和用量页
        文字粗细统一整理，日夜开关改矢量绘制（不再被 Windows 换成彩色 emoji）
  v3.0  面向开源：管家不再假设「DSH 装在某个固定位置、一定用 pnpm」——
        自动探测工作目录、启动命令自动识别，首次运行有引导；
        补上启动器源码和编译脚本，README / MIT 协议 / .gitignore 齐活

【小提示】
  整个文件夹可以随便搬到别的位置（D盘、U盘都行），
  只要桌面快捷方式重新指向新的 DSH管家.exe 即可。
